# Grappling Hook Prototype

A grappling hook movement prototype built in Unreal Engine 5 using C++.

## My Role

I implemented the core character and grappling gameplay systems in C++,
including player movement, grappling mechanics, input handling.

## Technical Highlights

### Grappling Movement
Implemented a physics-based grappling hook system that allows the player
to attach to different surfaces and use the grapple to influence their movement.

### Character System
Implemented the player character and movement logic in C++.

### Player Input
Implemented player input and control through a custom Player Controller.

## Engine / Tools

- Unreal Engine 5
- C++
- Blueprints
- Physics
